# Third-Party Evaluation and Notices

Last reviewed: 2026-09-29

This file records external projects evaluated for JARVIS V0.5. No source code from the four repositories listed below has been copied into this repository as of this review.

## HoloJarvis

- Repository: https://github.com/wqq64842-commits/holojarvis
- License reported by repository: MIT
- Intended use: implementation reference for local ASR, tool loop, MCP bridge, OpenAI-compatible calls and system TTS fallback.
- Excluded: plaintext API-key files, JSON-only memory design, Tkinter UI, restart-only provider changes, cloned voice assets.

## jarvis-holographic

- Repository: https://github.com/wantsleeps/jarvis-holographic
- License reported by repository: MIT
- Intended use: visual reference for a dynamic core, HUD depth and state feedback.
- Excluded: frontend API-key injection, external-CDN runtime dependency and camera gestures as a V0.5 requirement.

## Assistant-X-OpenClaw

- Repository: https://github.com/RubinTry/assistant-x-openclaw
- License reported by repository: MIT
- Intended use: implementation reference for Sherpa-ONNX keyword spotting, offline ASR/TTS, interruption, continuous conversation and hot-word correction.
- Excluded: mandatory OpenClaw Gateway dependency, repository voice/biometric assets and any film or actor voice imitation.

## Aervox-harness

- Repository: https://github.com/3yearsZhuang/Aervox-harness
- Source-code license reported by repository: GNU Affero General Public License v3 or later.
- Documentation license reported by repository: CC BY-NC-SA 4.0.
- Use: architecture observation only.
- Restriction: do not copy or adapt its code or documentation into JARVIS.

## Incorporation rule

Before copying or adapting any MIT-licensed file, append the exact repository commit, original path, copyright notice, files incorporated and material modifications here. Do not import media, voice, biometric or branding assets without a separate rights review.
